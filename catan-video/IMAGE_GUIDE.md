# Drop Your Images Here

Place photos in `images/` folder. Name them to help the script assign them to the right scenes:

| Scene | What to name it | Photo to use |
|-------|----------------|--------------|
| Full board (intro) | `board_full.jpg` | The overhead wide shot of the whole board |
| Ocean/sea | `ocean.jpg` | Blue water tiles at the edge |
| Forest | `forest.jpg` | Close-up of dark green forest hex |
| Mountain/ore | `mountain.jpg` | Gray mountain hex with snow |
| Grain | `grain.jpg` | Yellow wheat field hex |
| Pasture | `pasture.jpg` | Teal/green hex with sheep (white pieces) |
| Wide pullback | `wide.jpg` | Another wide/overhead shot for the ending |

Any extras will be used as alternates. The script auto-assigns if names don't match exactly.
