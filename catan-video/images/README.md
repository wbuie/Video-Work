# Drop Images Here

Upload your Catan board photos to this folder.

Suggested names to help the script auto-assign scenes:
- `board_full.jpg` — overhead wide shot of the whole board
- `ocean.jpg` — blue water/sea tiles with ship piece
- `forest.jpg` — dark green forest hex close-up
- `mountain.jpg` — gray mountain hex with snow cap
- `grain.jpg` — yellow wheat field hex
- `pasture.jpg` — teal/green hex with sheep (white pieces)
- `wide.jpg` — second wide/overhead shot for the ending

Any extras are welcome — the more the better!
